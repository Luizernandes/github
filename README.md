Projeto: Simulação da Teoria de Carteiras de Markowitz
Este projeto implementa uma simulação da Teoria de Carteiras de Markowitz, com foco na otimização da alocação de ativos com base em risco (volatilidade) e retorno esperado. A análise inclui o cálculo da fronteira eficiente, índice de Sharpe, e a visualização gráfica dos portfólios simulados.

Objetivo do projeto
O objetivo é demonstrar de forma prática os fundamentos da Teoria Moderna de Portfólios, proporcionando uma ferramenta interativa e educacional para analisar combinações de ativos de forma eficiente.

Conteúdo
Markowitz - Todo o passo a passo da simulação.
Cálculo de retorno e volatilidade esperada
Geração de múltiplos portfólios simulados
Cálculo do índice de Sharpe
Identificação do portfólio ótimo
Plotagem da fronteira eficiente com destaque para o portfólio de Sharpe máximo
